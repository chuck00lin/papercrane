# manuscript/

The render. LaTeX source where every number is a `\fact{}` and every figure is registered
with its run, the fact ids it depends on, and its hash.

```
manuscript/
├── main.tex             class, front matter, \input order
├── sections/*.tex       human prose; working notes behind `%!` (stripped for submission)
├── facts-map.yaml       which fact ids the paper uses, display precision, literal allowlist
├── facts.tex            GENERATED by tools/render-facts.py; never edited
├── figures.yaml         figure id → run, fact ids it depends on, file, sha256
├── labels.yaml          display labels and remaps (e.g. data row B shown as Row A)
└── figures/             rendered figure files, copied from experiment plot outputs
```

## Using a fact in prose

```latex
The tuned controller held a mean lateral RMSE of \fact{lane_rmse_tuned}~cm over
\fact{episodes} episodes, against \fact{lane_rmse_baseline}~cm for the baseline.
```

`facts-map.yaml`:

```yaml
facts:
  lane_rmse_tuned:    {id: EXP-000-example.r02.lane_rmse_cm, precision: 1}
  lane_rmse_baseline: {id: EXP-000-example.r01.lane_rmse_cm, precision: 1}
  episodes:           {id: EXP-000-example.r02.episodes,     precision: 0}
allow_literals:                 # numerals that are legitimately typed in prose
  - "2026"                      # years
  - "^[0-9]+(\\.[0-9]+)*$"      # section numbers in cross references
```

## Checks that apply here

numerals (no bare numbers; super/subscripts such as R$^2$ and the contents of equation
environments are exempt), figures (hash match), terminology, cross-ref. Run `make check`.
