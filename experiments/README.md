# experiments/

One folder per experiment. The folder is the registry entry, the design contract, the run
log, and the figures for that experiment. Raw outputs stay in the code space.

```
experiments/
└── EXP-001-short-slug/
    ├── experiment.yaml      design contract (schema: schemas/experiment.schema.json)
    ├── notes.md             human notes; never cited by identity or manuscript
    └── runs/
        └── r01/
            ├── run.yaml     run record (schema: schemas/run.schema.json)
            ├── figures/     figure files the code space emitted for this run (optional)
            └── raw/         gitignored; optional local mirror of code-space outputs
INDEX.md                     GENERATED by tools/status.py --write; never edited
```

## Rules

- A run is dispatched only when `experiment.yaml` validates and the design-review skill has
  passed (no targeted claim is disallowed; every targeted claim maps to an emitted fact).
- `status` moves `designed → running → frozen` or `→ abandoned`. A redesign after data
  exists is a new experiment with `supersedes:` set; the old one becomes `superseded`.
- `acquisition_log` lists what must be written down on the day of acquisition. The
  experiment agent asks for each item before marking the first run complete.
- Figures are produced by the code space from the same outputs that became facts, and
  copied under `runs/<run>/figures/`. A figure in the manuscript names its run and the fact
  ids it depends on in `manuscript/figures.yaml`.

## Managing many runs (imported from the first generation's compute repo)

- Every run carries a **variant tag** (`variant: default`, `variant: ct06_ss`, …) and may
  name a `baseline_run` and a one-line `change_vs_baseline`. That is what makes an A/B
  series readable six months later.
- `python3 tools/status.py` prints the registry (status, runs, frozen runs, latest variant,
  ADRs); `--write` regenerates `experiments/INDEX.md`.
- `python3 tools/compare.py --experiment <id>` prints the leaderboard: one row per run, one
  column per emitted fact, superseded values marked. `--fact <name>` compares a fact across
  experiments.
- `python3 tools/impact.py --run <exp>.<run>` answers "what must change in the paper now that
  this run is frozen": facts-map keys, manuscript lines, figures, claim rows, evidence rows.
  `--apply` rewrites `manuscript/facts-map.yaml` to the new run so `make render` picks it up.
  This is the tool that keeps a new experiment from turning the manuscript into a mess.
- A campaign (a series of experiments toward one claim) may keep a retrospective in
  `experiments/<id>/notes.md` of its last member; the registry itself stays flat.
