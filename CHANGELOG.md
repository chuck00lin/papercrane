# Changelog

## 0.1.0 — 2026-10-27

First public release. Research preview.

- Nine-stage lifecycle with three human-led stages (Idea, Design, Interpret).
- Design contracts pre-registered against the claim map; experiment registry with run
  records, variants and a leaderboard.
- Code-space adapter contract; file-queue bus; `dispatch`, `freeze`, `render-facts`,
  `impact`, `status`, `compare`.
- Frozen, hash-pinned facts; `\fact{}` macros; a checker for schemas, hashes, anchors,
  bare numerals, terminology, boards and figures.
- Eleven protocol skills written from concepts; taste lives in data files.
- Toy pipeline, `make demo`, `make pdf`, pytest suite, CI.
